# Test plan — Pi ST 2110 / NMOS island

**Reconstructed 2026-06-08** from the verified project state in `RESUME.md` / `RESTORE.md`
(the original was worked out in chat and never saved to a file). Each test lists how to
run it and the expected result actually observed during development.

## Conventions
- **Pi** commands run over SSH (`ssh dgperkins@pi5-nmos.local`); media-island `eth0` = `10.10.10.1`.
- **PC** commands run in WSL (`wsl -d Ubuntu`, root via `-u root`); island `eth1` = `10.10.10.2`.
- Senders/servers must be running first — `sudo bash ~/launch-all.sh` on the Pi,
  `pc/restore.ps1` on the PC (see `RESTORE.md`).
- Addresses: audio `239.10.10.10:5004` · video `239.10.10.20:5005` · monitor `:8095` ·
  web clock `:8000` · NMOS registry `:8080` / node `:8090`.

---

## T0 — Island connectivity (prerequisite)
- **Run (PC):** `ping 10.10.10.1`
- **Pass:** replies < 1 ms on the wired island. If this fails, fix static IPs before anything else
  (Windows `Ethernet` = `10.10.10.2`, Pi `eth0` = `10.10.10.1` via `nmcli`).

## T1 — ST 2110-30 audio (L24 multicast)
- **Run (Pi):** audio sender from `launch-all.sh` (L24, 48 kHz, stereo, 1 ms ptime → `239.10.10.10:5004`).
- **Run (PC, local WSL session):** GStreamer receiver (needs `PULSE_SERVER=unix:/mnt/wslg/PulseServer`).
- **Pass:** 440 Hz tone (or program audio) audible on Windows speakers, no dropouts.
- **Gotcha:** a detached/background `gst` is **silent** — audio needs a real local WSL session.

## T2 — ST 2110-20 video (RFC 4175 raw)
- **Run (Pi):** video sender from `launch-all.sh` (UYVY 320×240, 59.94, → `239.10.10.20:5005`).
- **Run (PC):** `pc/video-web.py` (auto-started by `restore.ps1`); open `http://localhost:8095`.
- **Pass:** live video paints in the Windows browser via the MJPEG transcode path.
- **Gotcha:** WSLg will **not** display a native GStreamer video window — always use the browser path.

## T3 — PTP (linuxptp)
- **Run (Pi):** single `ptp4l -i eth0 -m -S` grandmaster (kill extras: `sudo pkill ptp4l` then start one).
- **Run (PC):** PTP follower; observe `pmc`/log output.
- **Pass:** follower **discovers** the Pi grandmaster. Full lock is **not** expected under WSL (known limitation).

## T4 — PTP web clock
- **Run (Pi):** `master-clock-web.py` (from `launch-all.sh`).
- **Pass:** `http://pi5-nmos.local:8000` shows the live studio clock; opens on the iPad too.

## T5 — NMOS IS-04 (registry + node)
- **Run (PC):** Docker in WSL — registry + virtnode (`docker compose -f docker-compose.wsl.yml up -d nmos-registry nmos-virtnode` in `/root/easy-nmos`).
- **Pass:** registry reachable at `:8080`, node at `:8090`; node and its receivers appear in the registry.
- **Gotcha:** the virtnode **regenerates resource UUIDs** on restart — always resolve receivers by **label**, never cached UUID.

## T6 — NMOS IS-05 take (audio gating)
- **Run (PC, local WSL session):** `python3 pc/activation-watcher.py`, then `python3 pc/take.py on` / `off`.
- **Pass:** `take on` starts the GStreamer audio receiver (resolved by label) and audio is heard; `take off` stops it.
- **Gotcha:** the receiver has **2 transport-param legs** — PATCH only `master_enable` + activation, not a 1-element `transport_params`.

## T7 — RTP jitter measurement
- **Run (PC):** `python3 pc/jitter-meter.py` (kernel RX timestamps).
- **Pass / baseline:** wired island mean ≈ **1000 µs**, std-dev ≈ **600 µs** (bursty — no ST 2110-21 shaping + WSL RX batching). Use this as the reference for any wired-vs-WiFi comparison.

## T8 — JPEG XS (ST 2110-22) encode/decode demo
- **Run (PC):** `bash pc/jxs-demo.sh` (SVT-JPEG-XS encode→decode + comparison; FFmpeg + libs from `svt-ffmpeg-build.sh`).
- **Pass:** produces encoded `.jxs` + decoded frames and a side-by-side comparison; output under `jxs-demo/` (gitignored).

## T9 — JPEG XS stress / quality comparison
- **Run (PC):** `bash pc/jxs-stress.sh` (after `jxs-demo.sh` has captured `/tmp/orig.yuv`).
- **Pass:** prints byte sizes for JPEG XS bpp1 vs JPEG q15, and writes three zoomed noise-block PNGs
  (`zoom_1_uncompressed`, `zoom_2_jpegxs_bpp1`, `zoom_3_jpeg_q15`) into `jxs-demo/` — JPEG XS visibly cleaner than JPEG at comparable size.

## Reboot recovery check
After a Windows reboot, run the 2-step restore (`RESTORE.md`) then re-run **T0–T2** as a smoke test.
To confirm WSLg windows survived the reboot: in a local WSL terminal, `DISPLAY=:0 xeyes` should paint a window.
